HOW TO ADD MORE PHOTOS
1. Put new photos in this folder.
2. Add another .photo-card in the Gallery section of index.html.
3. For 2024/2026, replace/add the corresponding image names and year labels.

FREE PUBLISHING
- GitHub Pages: create a repository, upload these files, then enable Pages from Settings > Pages.
- Netlify: drag this folder/zip into Netlify's deploy area.
