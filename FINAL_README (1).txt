MANA VINAYAKA YOUTH – FINAL WEBSITE PACKAGE

Includes:
- Admin login
- Gallery upload by year (2024/2025/2026)
- Home background photo upload from Admin
- Latest uploaded hero photo automatically becomes the home background
- Sponsor names managed from Admin and auto-scroll on public site
- Supabase Storage + Auth integration

Admin:
Open admin.html and sign in with the Supabase Auth account already configured as ADMIN_UID in config.js.

Home background:
Admin login -> Home Background Photo -> choose image -> Upload Home Background.

Gallery:
Admin login -> select year -> choose image/video -> Upload to Gallery.

Sponsors:
Admin login -> Sponsors / Supporters -> one name per line -> Save Sponsor Names.

Do not put a service_role/secret key in config.js. The included key is the public anon key.
